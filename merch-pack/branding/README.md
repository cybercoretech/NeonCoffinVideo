# Neon Coffin Video logo

Transparent coffin-and-wordmark brand logo, 2067 × 761 pixels. Hot pink NEON COFFIN, acid green VIDEO, and cyan VHS accents; based on the original coffin-cassette emblem.

- `neon-coffin-video-logo.png`: reusable full-resolution transparent artwork.
- `neon-coffin-video-logo.webp`: lossless website version.

Keep the artwork's aspect ratio and allow breathing room around the mark. The website footer displays it up to 420px wide and scales it to fit phones. The logo's brand colors stay fixed when a theme changes.
