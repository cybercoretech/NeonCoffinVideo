# Fourthwall setup notes

Recommended initial route: a simple hosted Fourthwall storefront with a Shop link from neoncoffinvideo.site. There is no need to configure Cloudflare DNS or embed checkout for the first version.

1. Go to [Fourthwall](https://fourthwall.com/) and choose **Start now**. Sign up with email, Google, or Apple.
2. Set the shop name/site title to **Neon Coffin Video**. Fourthwall keeps the account's legal name private; the creator name is what customers see.
3. Verify the email address and complete the dashboard onboarding.
4. Go to **Products → Create New Product → Design something new**. Choose one garment first (a tee is a simple sample launch), upload an approved transparent PNG from `print/png/`, set placement and scale, and inspect every garment color in the product preview.
5. Set a retail price after checking the product's displayed base cost, expected shipping, and payment processing. Add a concise product description and select which variants to offer.
6. Customize the storefront title, colors, logo, and homepage; preview it on mobile and desktop. Keep products unpublished until the artwork and product preview are approved.
7. Add payout and required tax/payment details directly in Fourthwall, review its terms and payout requirements, then publish when ready.
8. Copy the public shop URL. Add it to the Neon Coffin site's Shop button/navigation as an external link. A custom domain can be considered later; it is optional for launch.

## Storefront illustration artwork

Use `print/png/neon-coffin-storefront-transparent-edges-source-1145x1374.png` if testing the illustrated storefront on apparel; its edge transparency lets the garment show through. It is a concept-sized file and may be too soft at large print sizes. Do not use the rejected opaque upscaler input; it showed as a gray block against the shirt. Fourthwall's upscaler requires an opaque image, so it is not suitable for this transparent-edge version without flattening it to a reliably matching garment color.

Fourthwall states that catalog products have a per-product base cost deducted from the selling price, with no monthly subscription or upfront product inventory costs. US credit card processing is listed as 2.9% + $0.30. Fourthwall says it acts as Merchant of Record and handles sales-tax collection/remittance for its checkout. Recheck the current terms and exact costs in the dashboard before publishing.
